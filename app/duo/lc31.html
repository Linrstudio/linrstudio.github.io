Day 31：Multi-Agent 协作总览：Supervisor 模式

一个任务不再由一个 Agent 从头做到尾，而是由一个 Supervisor（主管）分发给多个子 Agent，各自做完再汇总。先看图，再闯关。

为什么要多个 Agent：单 Agent 的三块天花板

天花板 1：上下文 —— 一个人全记住，越堆越高

一个 Agent 要同时记住规划、检索结果、工具输出、校验意见，上下文越长越容易顾此失彼；分工后，每个子 Agent 只看自己那部分。

天花板 2：能力 —— 一把瑞士军刀，开不了三把锁

检索、执行、校验是三种不同的活，一个提示词很难同时把三件事都做到最好；分开写提示词、分开配工具，各自才能调优。

天花板 3：并行 —— 单车道排队 vs 三车道同时开工

单 Agent 只能一步一步来；多个子 Agent 可以同时动手，总耗时从“各步相加”变成“最慢的那步”。
