最快的 Gemini

Gemini 4 Hydrogen 今天上线，Google 最快模型进 Search

Google 今天开始在 Search 中推送 Gemini 4 Hydrogen，这是目前最快的 Gemini 模型，主打写代码和 Agent 任务。默认高思考档下比 Gemini 3.8 Flash 快 2.5 倍，Antigravity 里的 Orchestrator 能在一次会话中切换 Hydrogen 与 Carbon。

笔记本跑 145B

Edge0-145B 开源，1450 亿参数模型跑上笔记本

Edge0 11 月 12 日开源了 Edge0-145B，1450 亿参数的模型能在 48GB 内存的笔记本上跑，号称 80+ token/秒。DeepSWE 1.1 拿了 64.6 分，但分数都是厂商自己测的，技术报告还没出，未经独立验证。

通用模型接管

OpenAI 解散机器人团队，通用模型直接接管

OpenAI 正在解散独立机器人团队，研究员分流到其他组。公司的说法是 GPT-6 Astra 这类通用模型能直接控制机器人，不再需要专门的机器人部门。

Agent 能花钱了

ChatGPT Wallet 上线，Agent 能替你花钱了

OpenAI 的 Dots Agent 现在能代用户下单购买了，ChatGPT Wallet 让 Agent 也能花钱。同批还有 Perplexity 开源 Decider v1.3 决策模型、DeepSeek App 能力开放 API。

50 种 UI 行为

Vercel UI SDK 发布，50 多种 UI 行为给 AI 编程 Agent

Vercel UI SDK 发布了 Apache-2.0 开源 Beta，给 AI 编程 Agent 提供 50 多种 UI 行为。支持 React、Vue、Svelte、Solid 和 Web Components，带直接控制 UI 的桥接。

本地 AI 1.0

llama.cpp 与 ggml 发布 1.0.0

跑本地 AI 的基础库 llama.cpp 与 ggml 发布了 1.0.0，开始按语义化版本管理，不兼容的 API 变更以大版本标记。

16 个记忆 token

斯坦福开源 Memorilla，16 个记忆 token 顶一个文档库

斯坦福开源了 Memorilla，一个给冻结 LLM 用的潜在记忆模块，把文档集合压成 16 个记忆 token。Qwen3-8B 上 FactKG 84.33%，文档 token 用量省了 108 倍。

长高没有捷径

青少年为长高服用抗癌药

这股 looksmaxxing 风潮里，一些青少年男孩把抗癌药 erdafitinib当成了长高药。强生表示该药从未获批用于增高。

关口前移

11月20日起，OpenAI 模型路由与网关须先获批

新规覆盖的不只是直接转售，经合作方托管或转售提供的模型接入同样在内。合作方还须保持与 OpenAI 相当的防护并协同执行限制。

名单再拉长

Copilot 12 月 14 日再退六个模型

GitHub 11 月 13 日宣布，12 月 14 日起 Copilot 再下线六个模型。六个里只有 Kimi K3 还没有官方接替者。

分身先行

OpenCode 2.3.0 让子智能体默认后台运行

OpenCode v2.3.0 派出的子智能体立刻返回会话 ID，父会话不用等它做完再继续。并行子智能体没有并发上限，派得越多 token 烧得越快。

只有十四天

Qwen4-Max 预览只到 11 月 25 日

阿里巴巴 11 月 11 日上线了Qwen4-Max 预览，上下文窗口为 100 万 token。它只对 Token Plan 订阅开放，没有按量付费入口。
