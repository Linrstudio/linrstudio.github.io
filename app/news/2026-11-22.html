Code Mode 实测快约 18%

Code Mode 把多次工具调用写成一段 JavaScript 一次跑完，而不是逐次来回问模型。实测 44 MB 日志 33 秒对 48 秒，花费 $1.43 对 $1.32。

它最适合成批改动，比如跨多文件的重构：下次要批量改一堆文件时，让 Code Mode 一次跑完，省下的主要是来回问模型的时间。
