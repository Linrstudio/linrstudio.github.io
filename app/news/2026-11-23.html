Claude SEO 插件免费做整站审计

一条命令 /plugin install claude-seo@gricdaniel-claude-seo 就能装上 Claude SEO。演示里 /seo audit 一次拉起 17 个专长智能体并行跑，给出整站审计报告。

插件自带 26 个 AI SEO 技能和 19 个子智能体，演示里一次审计的健康分是 57。不用再为整站审计单独订一份 SEO 工具：装上插件，在 Claude 里跑一次 /seo audit 就能拿到报告。

来源：https://www.facebook.com/reel/1107057322369112/

HyperFrames：描述一段视频，再逐帧改它

HyperFrames 把一段描述交给智能体，拿到的是一个可编辑的 HTML 视频工程。跑一次 npx hyperframes skills update 装好技能，就能让智能体出一段 10 秒片。

项目在 GitHub 上约 8.7 万星，最新版 v0.9.72 是 11 月 20 日发布的。视频不再是黑盒成品：描述改一处、逐帧改一处，改完还能再出片。

来源：https://kaifinds.sabaidev.la/finds/hyperframes-editable-ai-video-from-html

T3 Code 把 Claude Code 与 Codex 搬上手机

T3 Code 把 Claude Code、Codex 与 Cursor 收进一个手机入口，在本机上跑任务，在手机上批复和审 diff。它免费开源，不转卖 token，用的是你本地已经登录的订阅。

项目在 GitHub 上 66,397 星、11,579 个 Fork。手机上能批复、能审 diff，任务还在自己电脑上跑——出门也能接着管手头的编程任务。

来源：https://toris.kr/en/posts/t3-code-open-source-control-plane-mobile-guide
