新模型

Thinking Machines 发布 Inkling 2 Mini：循环推理的开源模型，笔记本就能跑

Thinking Machines 发布开源权重模型 Inkling 2 Mini：26.4B 参数的循环 Transformer，24 层中有 12 层每 token 跑三遍，用更少的输出 token 换更长的内部推理；SWE-bench Verified 79.2%，Artificial Analysis 智力指数 20 分追平 Qwen3.8 27B，成本约六分之一、速度约四倍；Apache 2.0 开源，32GB 内存的 Mac 就能跑。

新模型

NVIDIA Alpamayo 2 Edge：2B 推理 VLA 跑进车里，160–190ms 规划出轨迹

英伟达的开源车端模型 Alpamayo 2 Edge：2B 级推理视觉-语言-动作模型，专为 DRIVE AGX Thor 车内运行设计，读 6 路摄像头做 6.4 秒轨迹规划并给出因果解释；常规路况用特殊 token 跳过推理，像素到轨迹延迟 160–190ms；英伟达自测闭环每 15.15 公里才出一次责任事故，约 Qwen-Drive-1.0 4B 的 60 倍。

https://developer.nvidia.com/blog/running-av-reasoning-models-within-onboard-compute-and-latency-limits/

AI 安全

METR 警告：AI 变强速度已快过专家可靠评估的速度

METR 最新评估警告：前沿模型变强的速度已快过专家可靠评估的速度——在有明确反馈的编程任务上，模型多数时候已胜过资深人类专家；模型能啃下的任务时长每 3.6 个月翻倍，按此外推 2027 年 7 月能在 200 小时级任务上达到 50% 成功率；公开数据已不足以排除未来几年 AI 研究急剧加速的可能。

开发者工具

Perplexity Monitor API：联网搜索变成 24 小时哨兵

Perplexity 推出 Monitor API，把一次性的联网搜索变成持续哨兵：定时跑搜索或盯最多 10 个页面（价格页、更新日志等），自家决策模型按你定的目标过滤，只在相关、可信、新颖、及时全达标时经 webhook 推送；排期 15 分钟到每周或自定义 cron；Web 监测 $1/1000 次成功运行。内部测试 60 个话题 8 小时送出 63 条新鲜相关结果，约 Firecrawl 的 3 倍。

https://the-decoder.com/perplexitys-new-monitor-api-turns-web-search-from-a-one-off-query-into-a-nonstop-watchdog

来源：The Decoder

开发者工具

Google Gemini API 工具检索预览：工具库再大也不用全塞进提示词

Google 在 Gemini API 推出工具检索（预览）：Agent 接几十上百个工具时，不用再把全部参数 schema 塞进每次请求——加一个 tool_search、给工具标 defer_loading:true，模型只看到名字和简介，需要时 API 在同一次请求内加载完整 schema 再调函数；服务端检索不用自建索引，也支持 MCP 服务器与客户端自建检索；无额外收费，适用 Gemini 3.6 及以上（含全部 Gemini 4 模型）。

https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/

来源：Google 官方博客 · MarkTechPost

开发者工具

Localcode：Mac 上一条命令跑起本地 Agent 编程

登上 HN 首页的开源项目 Localcode：一条命令在 Mac 上跑起本地 Agent 编程，uv pip install localcode 即可；模型全跑本机（可选 12 个模型、169 种量化，含 Qwen 3.8、Inkling 2 Mini），自己读改文件、跑测试和构建；要 Apple Silicon Mac 与 16GB 以上内存，Apache 2.0 开源。

https://github.com/mjwsolo/localcode
