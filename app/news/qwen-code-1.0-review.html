Qwen Code 1.0 实测：先别急着 npm install

2026-11-13 · 真实安装实测 · 安装、登录与 CLI 本体

11 月 11 日，阿里把 Qwen Code 1.0 Preview 放出来了，还把商业 IDE Qoder 的 Agent 执行底座（Harness）一起开源了。

我是做前端的，正在往 Agent 开发转。这篇就是一个前端的视角：装了，跑了，没登录。先讲安装、登录和 CLI 本体，真让它写代码的部分，下篇登录后再测。

先说结论，三句话：

  1. 别用 npm 装，npm 上现在还是 0.27.3，1.0 只在 GitHub Releases 里，是免 Node 的原生包。
  2. 软件免费开源，推理不免费。免费 OAuth 今年 4 月就取消了，现在最顺的免费路是 Qoder 登录的限时推广。
  3. 1.0 真正的看点不是 CLI 本身，是开源出来的 Harness——Agent 的运行时底座，可以嵌进自己的产品里。

1.0 变了什么

Qwen Code 从一个终端编程助手，变成了一个开源的 Agent 运行时。Qoder 的 Harness 合进来之后，负责连模型、给工具、跑执行流程的那套东西都开源了，Apache-2.0。

两个提醒：1.0 现在是 Preview 分支，接口和行为都可能变，稳定版还在 0.27 线；阿里没公布 benchmark，性能的说法目前都是官方口径。

发布第二天（11 月 12 日）就推了 preview.1，修的是订阅账号登录后用不了订阅模型的问题。Day 1 的登录 bug，第二天修掉，节奏还行，但也说明 Preview 是真的 Preview。

安装：去 GitHub，别用 npm

我先踩的坑就是这个。npm 上 @qwen-code/qwen-code 的 latest 现在是 0.27.3，1.0 根本没上 npm，习惯性 npm install -g 装到的还是稳定版。

1.0 在 GitHub Releases 里，8 个原生包，macOS、Linux、Windows 都有，54MB 到 70MB，不需要另外装 Node.js。我装的 Linux x64 是 65MB，解压出来就一个 157MB 的文件，--help 实测 0.26 秒出结果。

认准 v1.0.0-preview.1，别下成 11 月 11 日那版 preview（有个登录 bug）。

第一次启动：先选登录方式

第一次跑 qwen，先问你信不信任这个文件夹——和 Claude Code 一样，信任之后它才能读写和执行这里的文件。

然后是关键一步：Connect a Provider，六个选项。

两个信息值得展开。第一，免费 OAuth 没了：以前每天 2000 次请求，4 月 13 日砍到 100，4 月 15 日直接取消，别再去找了。第二，Qoder 登录现在有个限时免费推广，用 Qoder 账号登录能领免费的 Qwen 模型访问，但官方没写截止日期，薅得到是运气。

付费路径一句话：Token Plan 每月 6 美元起，Qwen Plus 订阅每月 19 美元，Coding Plan Pro 每月 50 美元（第三方整理的价目，以官方为准）；也可以接自己的 OpenAI、Anthropic、Gemini Key，或者本地模型。

CLI 本体有什么

没登录也能看不少。--help 里几个值得说的：权限模式五档（default、accept_edits、bypass_permissions、dont_ask、auto），还有一个 --dangerously-skip-permissions；会话可以续跑，--continue、--resume、--fork-session 都在；自定义 Agent（--agent、--agents）加上 skills 命令和插件市场，明显对标 Claude Code 的 Skills 生态；MCP 有完整的管理命令；-p 可以非交互跑，适合接脚本和 CI。

一个有意思的细节：日志里混着中文的内部字符串，"宿主声明落地"这种——Qoder 那套东西合进来的时候，内部文案还没全翻成英文。

前端转 Agent 的视角

1.0 最值得看的不是 CLI 好不好用，而是 Harness 开源这件事。想做带 Agent 能力的产品，底座从哪来？自己写编排、工具调用、会话管理、权限控制，工作量不小。Qwen Code 1.0 开源的，就是阿里在 Qoder 里跑生产的那套底座，Apache-2.0，可以商用，可以嵌进自己的产品。

Preview 阶段接口还可能变，现在拿它做生产还早。但方向很清楚：Agent 的运行时正在变成基础设施，拼的是谁用得好，不是拼谁有框架。

结论

  • 想尝鲜：去 GitHub 下 preview.1，用 Qoder 登录领限时免费额度。
  • 想上生产：等稳定版。
  • 想学 Agent 开发：把 Harness 的代码当教材看，比只看文档有用。
