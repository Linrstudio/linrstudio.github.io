Claude Code 用三图一视频做出爆款 iPhone 界面

Breeje 用 Claude Code 做的两款 iPhone 应用界面，在 X 上获得了 28 万次观看和 7200 次收藏。

详细解读

做法可以拆成三步：先给 Claude Code 3 张 UI 参考图，再给 1 段动效视频，最后做 3 轮修改。参考图定的是风格——配色、排版、组件长什么样；动效视频定的是感觉——元素怎么动、多快、什么缓动。直接给图比用文字描述「现代、简洁、高级」有效得多，模型不用猜你要什么。

这套做法好用，是因为它治住了 AI 做界面最常见的毛病：千篇一律。没有参考的时候，模型默认往「平均好看」靠，做出来的界面都像一个模子。参考图把审美锚定在一个具体的东西上，动效视频又补上了静态图给不了的时序信息。3 轮修改是收敛过程：照着做的时候，3 轮可以这样分，第一轮定结构，第二轮调细节，第三轮抠质感。

前端和 UI 的朋友可以直接套这个流程：做 demo、做落地页、给客户出方案，手头有喜欢的 App 截图和一段动效视频就能开始，不需要先学什么新工具。
