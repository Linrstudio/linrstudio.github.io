家长起诉谷歌：学校 Chromebook 上的 AI 加剧女儿危机

13 岁女孩的家长在加州起诉谷歌，指控学校 Chromebook 上的 Gemini 在数月交流后加剧了她的心理危机。诉讼几天后，谷歌宣布 2027 年初起为 K-12 学生默认关闭 Gemini 等 AI 工具，学校须主动选择开启。

开发者工具

Claude Code 反超 Copilot，成最常用编程工具

JetBrains 对 1.5 万多名开发者的调查显示，Claude Code 的工作使用率在半年里从 18% 涨到 39%。31% 的开发者还把它列为自己最常用的编程工具，粘性比名气更能说明问题。

  • GitHub Copilot 使用率：21%
  • 每周用编程智能体：90%
