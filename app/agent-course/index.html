Agent 实战课：从 RAG 到 Loop Engineering

RAG · Agent · Loop Engineering 每天一课

这门课把两个公开面试知识库（km1994/AIGC-Interview-Book 的 RAG、Loop Engineering 与 Agent 部分，bcefghj/ai-agent-interview-guide 的面试八股文）整理成 22 天的课：问答体拆开重组成可教的课，先讲清概念与为什么，再给可跑的代码，最后落到面试题与简历讲法。两个库重叠的主题（ReAct、MCP、工具安全、记忆与 RAG、规划器-执行器等）只在一课主讲，其余课交叉引用，不重复讲。目标岗是 AI 应用落地 / Agent 前端 / Agent 工具链，不对标 LLM 基建岗；大模型基础只作附录速通。

每课的固定结构

1. 核心解释：先讲概念和一张心智地图，不堆 API。
2. 代码示例：能直接跑的最小代码，关键行有注释。
3. 小测验：当页可点、可判分，答完再看解析。
4. 面试题与答案：按“面试官想听的点”写，不是背诵版。
5. 加分项：生产视角、上线视角、简历讲法。
