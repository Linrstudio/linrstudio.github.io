LangChain 30 天实战课

从小白到 AI Agent 开发 每天一课

这不是只讲 API 的课。每一课都有同一套结构：核心解释 → 代码示例 → 小测验 → 面试题与答案 → 加分项，最后落到一个能放进简历的项目上。目标岗是 AI 应用落地 / Agent 前端 / Agent 工具链，不对标 LLM 基建岗。

每课的固定结构

1. 核心解释：先讲概念和一张心智地图，不堆 API。
2. 代码示例：能直接跑的最小代码，关键行有注释。
3. 小测验：当页可点、可判分，答完再看解析。
4. 面试题与答案：按“面试官想听的点”写，不是背诵版。
5. 加分项：生产视角、上线视角、简历讲法。

配套代码在学习计划的脚手架里：第 1 周对应 agent-core（手写循环 + LangGraph 版）。课程网页只讲思路和用法，动手跑代码用脚手架。
