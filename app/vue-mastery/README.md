# Vue 学练场

一个面向有 React 经验的前端开发者的静态学习工作台，按 8 周路线系统学习 Vue 2、Vue 3 与 uni-app。

## 内容与交互

- 今日任务：知识卡、5 道复习题、口头复述；完成后记录连续学习与经验值。
- 8 周路线：逐周目标、7 天任务和验收标准；可标记每日完成并自动记录单元完成度。
- 面试题库：30 道原理、API、迁移、跨端、性能和排错题；支持按主题、难度和关键词筛选，并记录错题及掌握情况。
- 框架对照：React 与 Vue 的响应式、逻辑复用、组件接口，以及 Vue 2/3 和 uni-app 的关键差异。
- 学习档案：连续天数、正确率、经验值、近 28 天打卡记录；可导出或清空本机数据。

## 发布

目录：`app/vue-mastery/`

GitHub Pages 路径：`https://app.qingyinhui.com/app/vue-mastery/`

纯静态页面，无构建步骤、无后端。学习进度写入当前浏览器的 `localStorage`，不会同步到其他设备或上传服务器。清理浏览器数据前可从“学习档案”导出 JSON 备份。

本地预览可在仓库根目录运行：

```sh
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/app/vue-mastery/`。
