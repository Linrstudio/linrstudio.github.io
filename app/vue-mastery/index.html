React⇄Vue
✦
先记住这条主线

React 更强调显式地描述状态如何驱动渲染；Vue 通过响应式依赖追踪自动知道哪些副作用需要重新执行。两者都能做好组件化、状态管理与性能优化，但心智模型不同。

MIGRATION EXERCISE

把熟悉的 React 习惯，翻译成 Vue 问题

挑一个你做过的 React 功能（表单、列表筛选或弹窗），先不写代码，回答下面三问，再去 Vue 3 实现。

01状态在哪里？

是组件本地状态、父级状态，还是跨页面共享状态？Vue 中用 ref/reactive、props/emit 还是 Pinia？

02谁依赖它？

React 中哪些组件重渲染？Vue 中哪些 effect 会订阅这个状态？有没有不必要的依赖？

03换端会怎样？

如果这个功能进 uni-app，是否依赖 DOM、浏览器 API 或平台特有的交互？
