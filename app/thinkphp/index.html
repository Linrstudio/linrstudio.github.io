ThinkPHP 面试实战课：12 天从入门到面试

ThinkPHP 8.x ThinkJS 对比 每天一课 · 约 60 分钟

这门课面向有前端背景、要面试 PHP 岗位的开发者：以 ThinkPHP 8.x 为主线，12 天讲透请求生命周期、路由、控制器、中间件、数据库、模型、验证与安全、缓存与队列、容器与门面、多应用与部署，最后用一课做 ThinkPHP vs ThinkJS 全面对比与面试串讲。每课先讲清机制与"面试官想听的点"，再给逐行注释的可跑代码，最后落到面试题与简历讲法。

为什么拿 ThinkJS 做对比
ThinkJS 是 360 奇舞团开源的 Node.js 框架，作者李成银 2013 年底参考 ThinkPHP 起步，许多特性直接来源于 ThinkPHP：Controller、Model、Middleware、Adapter 的命名与目录结构高度相似，连数据库链式 API 的写法都像同一个人写的。如果你熟悉 JS/Node，用 ThinkJS 做锚点，ThinkPHP 的概念几乎不用死记——只需要分清一处根本不同：PHP-FPM 是同步阻塞、每请求重建应用；Node 是异步非阻塞、常驻进程。Day 12 会把这张对照表一次讲透。

每课的固定结构

1. 核心解释：先讲机制和一张心智地图，不堆 API；每个概念给面试答法。
2. 代码示例：能直接跑的最小代码，逐行注释；关键 PHP 语法有解释，能用 JS/TS 对照就对照。
3. ThinkJS 对比：有真实相似点时才写，具体到类名、方法名、目录结构。
4. 小测验：当页可点、可判分，答完再看解析。
5. 面试题与答案：按"面试官想听的点"写，不是背诵版。
6. 加分项：生产视角、简历讲法。
