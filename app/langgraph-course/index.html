LangGraph 14 天实战课

从一张图到多 Agent 协作 每天一课

LangChain 课里你已经手写过 Tool Calling 循环，LangGraph 就是把这个循环画成一张图：节点是步骤，边是流向，状态是共享的记事本。这门课 14 天讲完一张图的全部本事：第 1 周学图本身，第 2 周拿一个真实项目（广告投放用户之声 Agent）实战，最后落到一个能放进简历的多 Agent 项目上。目标岗是 AI 应用落地 / Agent 前端 / Agent 工具链，不对标 LLM 基建岗。

学习路线
第 1 周：Day 1 图是什么 → Day 2 状态与 Reducer → Day 3 条件边与路由 → Day 4 工具节点与 ReAct → Day 5 Checkpoint 与断点续跑 → Day 6 人工介入与中断 → Day 7 子图、多 Agent 图与复盘
第 2 周：Day 8 项目全景 → Day 9 数据层 → Day 10 分析层 → Day 11 对话追问 → Day 12 权限与安全 → Day 13 需求闭环 → Day 14 知识库更新与复盘

每课的固定结构

1. 核心解释：先讲概念和一张心智地图，不堆 API。
2. 代码示例：能直接跑的最小代码，关键行有注释。
3. 小测验：当页可点、可判分，答完再看解析。
4. 面试题与答案：按“面试官想听的点”写，不是背诵版。
5. 加分项：生产视角、上线视角、简历讲法。
